# Knowledge: `scripts/qa/test-idts56-smart-assign.js`

## English / Tiếng Việt

The Smart Assign fixture seeds one exact linked Developer and one legacy unlinked Developer. It proves the linked candidate remains available, the unlinked candidate is omitted from `AssignableDevelopers`, and direct assignment is rejected without changing the existing Bug owner.

Fixture Smart Assign seed một Developer linked exact và một Developer legacy chưa link. Fixture chứng minh candidate linked vẫn available, candidate chưa link bị loại khỏi `AssignableDevelopers` và direct assignment bị reject mà không đổi owner Bug hiện có.
