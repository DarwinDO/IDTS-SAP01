# Knowledge: `app/bug-management-ui/package-lock.json`

## English

This lockfile freezes the Bug Management UI build dependency graph. Gate 6.4 advances only the top-level `version` and `packages[""].version` to `0.0.6`; all dependency entries remain unchanged. The two values must match `package.json` and `webapp/manifest.json` so `npm ci` and the HTML5 release identity describe the same artifact.

### Safe editing

- Never hand-edit transitive dependencies to silence audit output.
- Check package/manifest/lock parity, run the focused UI contract, and build the production ZIP.

## Tiếng Việt

Lockfile này cố định dependency graph build của Bug Management UI. Gate 6.4 chỉ tăng `version` top-level và `packages[""].version` lên `0.0.6`; toàn bộ dependency entry giữ nguyên. Hai giá trị phải khớp `package.json` và `webapp/manifest.json` để `npm ci` cùng release identity HTML5 mô tả đúng một artifact.

### Sửa an toàn

- Không sửa tay dependency transitive để làm mất audit warning.
- Kiểm parity package/manifest/lock, chạy UI contract tập trung và build ZIP production.
