# `i18n.properties` / `i18n_en.properties` - IDTS-70 AI review UI text note

## English

### What this note covers

IDTS-70 adds reusable AI review text keys used by `AiReviewUi.js` and Smart Assign.

### Beginner explanation

In SAPUI5, visible UI text should live in i18n files instead of being hardcoded in controllers. This keeps wording consistent and makes later translation possible.

For AI suggestions, this matters more than usual. The UI must not expose implementation words such as provider, prompt, token, debug, SQL, or endpoint. These keys keep the visible AI review language product-facing and simple.

### Important source anchors

- **Location**: `aiReviewLoading`
  **IDTS concept**: Pending suggestion state.
  **Impact if broken**: Users may see an empty explanation area while Smart Assign waits for backend explanation.
  **Must check together**: `AiReviewUi.loading(...)` and Smart Assign candidate loading.

- **Location**: `aiReviewStatusReady`, `aiReviewStatusLowConfidence`, `aiReviewStatusDisabled`, `aiReviewStatusUnavailable`
  **IDTS concept**: Human-readable AI suggestion status.
  **Impact if broken**: Disabled, failed, or low-confidence suggestions can look like normal recommendations.
  **Must check together**: SAP Fiori message/status guidance and `scripts/qa/test-idts70-ai-review-ui.js`.

- **Location**: `aiReviewDecisionHint`
  **IDTS concept**: Human review remains mandatory.
  **Impact if broken**: UI may imply AI has already made the decision.
  **Must check together**: `SmartAssignDeveloper.js` explanation cell and QA UI/UX evidence.

### Cross-folder impact

- `app/bug-management-ui/webapp/ext/ai/AiReviewUi.js` reads these keys through the `getText` adapter.
- `app/bug-management-ui/webapp/ext/actions/SmartAssignDeveloper.js` displays the decorated result.
- `scripts/qa/test-idts70-ai-review-ui.js` verifies required keys exist and do not contain internal/dev-facing terms.

### Safe editing checklist

- Keep English and fallback English bundles aligned.
- Do not add internal implementation terms to visible copy.
- Keep labels short enough for a dialog table cell.
- Rerun `npm run qa:idts70:programmatic`.

## Vietnamese

### Note này nói về gì

IDTS-70 thêm các i18n key dùng chung cho AI review UI, được `AiReviewUi.js` và Smart Assign sử dụng.

### Giải thích cho người mới

Trong SAPUI5, text hiển thị trên UI nên nằm trong file i18n thay vì hardcode trong controller. Cách này giúp wording nhất quán và sau này dễ dịch hơn.

Với AI suggestion, điều này còn quan trọng hơn bình thường. UI không được lộ các từ triển khai như provider, prompt, token, debug, SQL, hoặc endpoint. Các key này giữ ngôn ngữ AI review ở mức sản phẩm, dễ hiểu cho người dùng.

### Important source anchors

- **Vị trí**: `aiReviewLoading`
  **Khái niệm IDTS**: Trạng thái suggestion đang được chuẩn bị.
  **Ảnh hưởng nếu sai**: User có thể thấy vùng explanation trống trong lúc Smart Assign chờ backend explanation.
  **Phải kiểm tra cùng**: `AiReviewUi.loading(...)` và luồng load candidate của Smart Assign.

- **Vị trí**: `aiReviewStatusReady`, `aiReviewStatusLowConfidence`, `aiReviewStatusDisabled`, `aiReviewStatusUnavailable`
  **Khái niệm IDTS**: Trạng thái AI suggestion ở dạng người dùng đọc được.
  **Ảnh hưởng nếu sai**: Suggestion bị tắt, lỗi, hoặc confidence thấp có thể nhìn giống recommendation bình thường.
  **Phải kiểm tra cùng**: guideline SAP Fiori về message/status và `scripts/qa/test-idts70-ai-review-ui.js`.

- **Vị trí**: `aiReviewDecisionHint`
  **Khái niệm IDTS**: Human review vẫn bắt buộc.
  **Ảnh hưởng nếu sai**: UI có thể làm user hiểu nhầm rằng AI đã quyết định xong.
  **Phải kiểm tra cùng**: explanation cell trong `SmartAssignDeveloper.js` và evidence UI/UX QA.

### Liên kết với file khác

- `app/bug-management-ui/webapp/ext/ai/AiReviewUi.js` đọc các key này qua adapter `getText`.
- `app/bug-management-ui/webapp/ext/actions/SmartAssignDeveloper.js` hiển thị kết quả đã được decorate.
- `scripts/qa/test-idts70-ai-review-ui.js` kiểm tra các key bắt buộc tồn tại và không chứa từ nội bộ/dev-facing.

### Checklist sửa file an toàn

- Không thêm từ triển khai nội bộ vào copy user thấy.
- Giữ label đủ ngắn để hiển thị trong ô table của dialog.
- Chạy lại `npm run qa:idts70:programmatic`.
