# `i18n.properties` / `i18n_en.properties` - IDTS-69 Smart Assignment Explanation supplemental note

## English

### What changed

IDTS-69 adds user-visible text keys for the Smart Assign explanation column, review message, loading state, unavailable state, review-required marker, and confidence label.

### Beginner explanation

SAPUI5 screens should not hardcode visible text directly inside JavaScript. Text is usually stored in i18n property files so it can be translated and reviewed separately. The Smart Assign dialog reads these keys through the resource bundle.

### Important source anchors

- **Location**: `smartAssignAiExplanationColumn`
  **IDTS concept**: Column title for reviewable AI explanation.
  **Impact if broken**: The table column may appear unnamed or confusing.
  **Must check together**: `SmartAssignDeveloper.js` table column.

- **Location**: `smartAssignAiNotice`
  **IDTS concept**: User-facing guardrail that explanation helps review but does not choose the assignee.
  **Impact if broken**: Users may over-trust AI output.
  **Must check together**: SAP Fiori AI guidance and Smart Assign browser evidence.
