# Knowledge: `i18n.properties`

## English / Tiếng Việt

Gate 3B adds localized copy for the existing-identity link label, current business-role label, preservation/readback notice, email label, send action, and queued result. The preservation notice explicitly names the same Users.ID, Developer Profile/responsibilities, Bug assignments, comments, and history. The English-first property set stays in parity with `i18n_en.properties`; no identity/provider value is interpolated into UI copy.

Gate 3B thêm copy i18n cho label link identity hiện hữu, label business role hiện tại, notice preservation/readback, label email, action gửi và kết quả queued. Notice nói rõ giữ cùng Users.ID, Developer Profile/responsibility, assignment Bug, comment và history. Bộ properties English-first giữ parity với `i18n_en.properties`; không interpolate giá trị identity/provider vào copy UI.

The cancellation copy is deliberately generic because the same server-owned button now covers both standard onboarding and existing-user identity-link invitations. It tells the PM that the current link stops working and a replacement can be sent; it does not expose the internal action name or invitation type.

Copy Cancel duoc viet tong quat vi cung button server-owned nay gio dung cho ca invitation onboarding thuong va link identity user hien huu. Copy noi ro link hien tai se dung hoat dong va co the gui invitation thay the; UI khong lo ten action noi bo hoac loai invitation.

Gate 4 adds confirmation and impact copy for responsibility changes. It states that existing Bugs keep their current assignee and that the PM must review the open-Bug impact count; it never promises automatic reassignment.

Gate 4 thêm copy confirmation và impact cho thay đổi responsibility. Nội dung nói rõ Bug hiện hữu giữ nguyên assignee và PM phải review số Bug đang mở bị ảnh hưởng; UI không hứa tự động reassign.
