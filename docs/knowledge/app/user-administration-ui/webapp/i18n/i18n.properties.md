## Gate 6.3 workload copy / Copy workload Gate 6.3

### English

The Gate 6.3 keys describe the Developer Workload tab, the read-only technical-assignee/current-action-owner distinction, search/refresh/load-more states, open/limit formatting, overload/overdue labels, the bounded Bug detail columns, and the same-origin `Open Bug` action. The wording is business-facing and does not expose OData, provider, identity, endpoint, or implementation details. `i18n_en.properties` carries equivalent English keys and `i18n_vi.properties` carries the Vietnamese counterparts.

- **IDTS concept**: Localized copy explains that open assigned Bugs belong to the technical assignee while `Needs Developer action` means the workflow is waiting for that Developer.
- **Impact if broken**: Users may confuse a workload indicator with authorization, or treat Current Action Owner as a second technical assignee.
- **Must check together**: `Main.view.xml` Workload tab, `DeveloperWorkloadDetails.fragment.xml`, `formatter.js` workload functions, and `scripts/qa/test-user-admin-workload.js`.

### Tiếng Việt

Wording hướng nghiệp vụ, không lộ OData, provider, identity, endpoint hoặc chi tiết implementation. `i18n_en.properties` giữ key English tương đương và `i18n_vi.properties` giữ counterpart tiếng Việt.

- **Khái niệm IDTS**: Copy localize giải thích Bug đang mở được tính theo technical assignee, còn `Needs Developer action` nghĩa là workflow đang chờ Developer đó.
- **Ảnh hưởng nếu sai**: User có thể nhầm workload indicator với authorization hoặc xem Current Action Owner như technical assignee thứ hai.
