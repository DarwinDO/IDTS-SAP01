## Gate 5 key anchors / Anchor key Gate 5

### English

The Gate 5 keys at `webapp/i18n/i18n.properties:118-154` cover the four catalog labels, the type column, `componentType`/`categoryType` form labels, safe load/change failures, count-only impact labels, bounded deactivation reason, and field-specific validation messages. `i18n_en.properties` must carry the same keys and equivalent meaning.

- **IDTS concept**: UI copy explains activate/deactivate and impact review without exposing entity names, SQL, provider internals, credentials, or hard-delete language.
- **Impact if broken**: A locale can omit a key, restore misleading wording, or leave validation controls without a readable message.
- **Must check together**: `Main.view.xml:287-314`, `EditCatalogItem.fragment.xml:5-20`, `CatalogImpact.fragment.xml:5-14`, and `scripts/qa/test-user-admin-ui.js:633-642`.

### Tiếng Việt

- **Khái niệm IDTS**: Copy UI giải thích activate/deactivate và impact review mà không lộ entity name, SQL, provider internals, credential hoặc wording hard-delete.
- **Ảnh hưởng nếu sai**: Một locale có thể thiếu key, khôi phục wording gây hiểu nhầm hoặc để control validation không có message đọc được.

### Safe editing / Sửa an toàn

Update both property files together. Keep user-visible copy localized and stable; do not interpolate raw server errors, identity/provider values, endpoints, or credentials. After changes, run the UI contract and inspect both locale key sets.

Luôn cập nhật hai file properties cùng nhau. Giữ copy user-facing được localize và ổn định; không interpolate raw server error, identity/provider value, endpoint hoặc credential. Sau khi sửa, chạy UI contract và kiểm tra cả hai bộ key locale.

## Gate 6.1 navigation and action copy / Copy navigation và action Gate 6.1

### English

Gate 6.1 adds six top-level tab tooltip keys at `app/user-administration-ui/webapp/i18n/i18n.properties:76-78,125-127`, three distinct row-action tooltip keys at `:31-33`, and the safe change-role hint at `:35`. The same keys and equivalent English meaning are present in `i18n_en.properties` and `i18n_vi.properties`; the Vietnamese bundle supplies localized wording for the new UI. The hint directs users to Manage Responsibilities when only availability, workload, or responsibilities need changing and does not expose provider, endpoint, identity, or backend details.

- **IDTS concept**: Localized copy separates navigation discovery, business action meaning, and the safe boundary between role changes and Developer responsibility maintenance.
  **Impact if broken**: A locale can hide a tab's purpose, make Change Role and Manage Responsibilities look interchangeable, or omit the safe guidance before a role-change request.
  **Must check together**: `Main.view.xml:28-35,37,121,230,279,390,440`, `ManageAccess.fragment.xml:15-20`, and `scripts/qa/test-user-admin-ui.js` parity assertions.

### Tiếng Việt

Các key giống nhau và ý nghĩa English tương đương có trong `i18n_en.properties` và `i18n_vi.properties`; bundle tiếng Việt cung cấp wording đã dịch cho UI mới. Hint hướng user sang Manage Responsibilities khi chỉ cần đổi availability, workload hoặc responsibility, không lộ provider, endpoint, identity hay backend detail.

- **Khái niệm IDTS**: Copy localize tách rõ việc khám phá navigation, ý nghĩa action nghiệp vụ và boundary an toàn giữa đổi role với quản trị Developer responsibility.
  **Ảnh hưởng nếu sai**: Một locale có thể che mất mục đích tab, làm Change Role và Manage Responsibilities trông như cùng một việc hoặc thiếu hướng dẫn lựa chọn an toàn trước request đổi role.
  **Phải kiểm tra cùng**: `Main.view.xml:28-35,37,121,230,279,390,440`, `ManageAccess.fragment.xml:15-20` và assertion parity trong `scripts/qa/test-user-admin-ui.js`.

### Safe editing / Sửa an toàn

Add user-facing copy to all three locale bundles together. Keep action tooltips short and verb-led, preserve equivalent meaning in Vietnamese, and never interpolate raw server/provider/identity values.

Thêm copy user-facing vào cả ba locale bundle cùng lúc. Giữ tooltip action ngắn, bắt đầu bằng động từ, giữ ý nghĩa tương đương trong tiếng Việt và không interpolate giá trị raw từ server/provider/identity.
