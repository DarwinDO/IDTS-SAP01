# Knowledge: `LinkExistingIdentity.fragment.xml`

## English

The dialog is intentionally small: safe existing-user ObjectIdentifier, a read-only current business-role ObjectStatus, a localized preservation notice that names the same Users.ID/Profile/responsibilities/Bug assignments/comments/history invariant, and one type-Email input. Send is disabled until the client-side email shape is valid and no provider field is offered.

## Tiếng Việt

Dialog cố ý tối giản: ObjectIdentifier user hiện tại an toàn, ObjectStatus business role read-only, notice localized về invariant giữ nguyên Users.ID/Profile/responsibility/assignment Bug/comment/history và một input type Email. Nút Send bị disable khi email chưa hợp lệ và UI không có field provider.
