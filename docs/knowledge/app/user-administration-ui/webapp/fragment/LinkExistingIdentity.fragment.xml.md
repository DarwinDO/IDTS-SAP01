# Knowledge: `LinkExistingIdentity.fragment.xml`

## English

The dialog is intentionally small: safe existing-user ObjectIdentifier, read-only preservation/readback notice, and one type-Email input. Send is disabled until the client-side email shape is valid and no provider field is offered.

## Tiếng Việt

Dialog cố ý tối giản: ObjectIdentifier user hiện tại an toàn, notice read-only về preservation/readback và một input type Email. Nút Send bị disable khi email chưa hợp lệ và UI không có field provider.
