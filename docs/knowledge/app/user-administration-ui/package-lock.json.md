# Knowledge: `app/user-administration-ui/package-lock.json`

## English

This lockfile freezes the User Administration UI build dependency graph. The top-level `version` and `packages[""] .version` mirror `package.json`; the dependency entries remain unchanged during the `1.0.10` content release. Use `npm ci --workspaces=false` for reproducible MTA builds and never hand-edit transitive package versions to silence audit output.

## Tiếng Việt

Lockfile này cố định dependency graph dùng để build User Administration UI. `version` top-level và `packages[""] .version` mirror `package.json`; các dependency entry không thay đổi trong release content `1.0.10`. Dùng `npm ci --workspaces=false` để build MTA lặp lại được và không sửa tay version transitive chỉ để làm mất audit output.

### Important source anchors

- **Location**: top-level `version` and `packages[""] .version`.
  **IDTS concept**: Reproducible UI release metadata.
  **Impact if broken**: Package, manifest, and deployable content can claim different releases or `npm ci` can reject the lock contract.
  **Must check together**: `package.json`, `webapp/manifest.json`, `mta.user-admin-ui-r3c.yaml`, and UI build verification.
