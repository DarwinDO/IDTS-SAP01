# Knowledge: `db/data/idts.cap-DefectCategories.csv`

## English

### What this file is for

Seed for DefectCategories (types of defects: functional, UI, performance, etc.).

Combined with Application Components to form ComponentCategories (the assignment key).

### IDTS impact

Directly affects classification during bug creation and the dependent value help.

Wrong categories break assignment matching.

### Links

ComponentCategories, Bugs, value-helps, read-models.
