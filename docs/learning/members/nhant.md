# NhanT Learning Ownership

## English

Primary files: QA scripts, browser harness, integration tests, and release evidence paths. Primary flow: QA and release evidence. Backup flow: monitoring/history backend diagnosis.

Before PASS, NhanT must explain what a test proves, what it does not prove, how to make a negative case fail safely, and how to turn a credible product finding into Jira evidence.

## Vietnamese

File primary của NhanT: QA script, browser harness, integration test và evidence path. Flow primary: QA và release evidence. Flow backup: monitoring/history backend diagnosis.

Trước khi PASS, NhanT phải giải thích test chứng minh được gì, chưa chứng minh được gì, làm negative case fail an toàn thế nào và chuyển product finding đáng tin thành Jira evidence ra sao.
