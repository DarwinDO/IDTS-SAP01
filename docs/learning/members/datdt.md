# DatDT Learning Ownership

## English

Primary files: assigned shell, login/profile, dashboard, List Report/monitoring, and AI review runtime files under `app/`. Primary flows: dashboard/history UI and backup authentication UI.

Before PASS, DatDT must trace a browser action to the OData request, explain the UI5/Fiori file that creates or consumes it, and identify the backend contract that supplies the data.

## Vietnamese

File primary của DatDT: các runtime file shell, login/profile, dashboard, List Report/monitoring và AI review đã được assign trong `app/`. Flow primary: dashboard/history UI và backup authentication UI.

Trước khi PASS, DatDT phải trace được browser action tới OData request, giải thích file UI5/Fiori tạo hoặc dùng request đó và chỉ backend contract cung cấp dữ liệu.
